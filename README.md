# Bubble Sort in C++

This repository contains a simple implementation of the Bubble Sort algorithm in C++.

## Features
- Sorts an array in ascending order.
- Uses adjacent element comparisons and swapping.
- Includes an early termination optimization using a boolean flag (`isSwap`).
- Detects when the array is already sorted.

## Example

**Input:**
```cpp
int arr[] = {5, 3, 1, 4, 2};
```

**Output:**
```text
1 2 3 4 5
```

## Time and Space Complexity
- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)
